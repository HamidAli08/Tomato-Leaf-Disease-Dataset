🍅 Tomato Leaf Disease Dataset

A curated and structured dataset for tomato leaf disease detection and classification using computer vision and deep learning techniques.
This dataset is designed to support research in smart agriculture, plant pathology, and AI-based crop monitoring.

📌 Dataset Overview

Domain: Agriculture / Plant Disease Detection

Crop: Tomato

Data Type: RGB leaf images

Use Case: Image classification, CNN training, benchmarking

Split: Training, Validation, Testing

The dataset contains six distinct classes of tomato leaf conditions collected under real-world scenarios.

🦠 Disease Classes

Bacterial Spot

Early Blight

Late Blight

Leaf Mold

Septoria Leaf Spot

Healthy Leaf
