# 🍅 Tomato Leaf Disease Dataset (Train / Val / Test)

This repository contains a **Tomato Leaf Disease Dataset** designed for training and evaluating deep learning models for plant disease detection.  
The dataset consists of **six classes**, split into **train**, **validation**, and **test** folders.
